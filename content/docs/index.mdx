## Introduction

**vdocs** is a private, cloud-hosted documentation framework and knowledge vault designed to be fast, flexible, and accessible from any device. It blends the sleek design of **Fumadocs** with a structured database backend.

## Core Concepts

### 1. One Unified Page Tree
Every document is a node in the tree. Categories, documents, and sub-pages share the same structure, allowing unlimited nested organization.

### 2. Typed Content Blocks
Content is stored as structured JSON rather than raw markdown files. This enables purpose-built forms for commands, multi-step runbooks, and job questionnaire responses.

### 3. Read and Edit on One URL
Seamlessly toggle between read mode with one-click copy buttons and edit mode with instant draft saves.
