## Why vdocs?

Most developers maintain scattered fragments of knowledge:
- A text snippet with tricky bash commands saved in random chat logs
- Previous job application answers stored across drafts
- System installation notes and bootloader fixes buried in old gists
- Resume PDFs and certificates stored in multiple cloud drives

**vdocs** consolidates everything into a single, lightning-fast private web application.

## Key Features

- **Fast Capture:** Quick Cmd+K palette to insert a command or Q&A pair from anywhere.
- **Copy with Ease:** One-click copy for terminal commands (with auto-stripped `$` prefixes) and job responses.
- **Self-Hosted Privacy:** Runs on your own Neon Postgres instance and Cloudflare R2 bucket.
